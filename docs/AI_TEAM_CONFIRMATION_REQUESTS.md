# AI팀 확인 요청사항

## 1. RGB 배포 골든 픽스처 원본 제공

**질문**

`golden_fixture_deploy.json`이 참조하는 원본 RGB 이미지 20장을 제공할 수 있나요?

**필요한 내용**

- `fixtures_deploy/` 원본 이미지 20장
- 각 이미지가 `golden_fixture_deploy.json`의 파일명 및 해시와 일치하는지 여부
- 결함 판정 이미지와 정상 판정 이미지의 구분
- 골든 이미지의 정본 저장 위치(Git LFS 또는 S3)

**요청 이유**

현재 RGB 모델 레포에는 골든 결과 JSON만 있고 실제 이미지가 없어 동일한 입력을 사용한 배포 회귀 검증을 재현할 수 없습니다.

## 2. CT ONNX 후처리 변경 승인

**질문**

CT ONNX 배포 후처리를 기존 `NMS + IOU`에서 `NMS + IOS + threshold 0.44`로 변경해도 되나요?

**현재 확인된 내용**

- CT 확인요청 회신에 기록된 기존 배포 설정: `NMS + IOU`
- ONNX 20장 검증 통과 설정: `NMS + IOS + 0.44`
- `IOS 0.44`에서는 20장 모두 판정·검출 개수·클래스·confidence 기준 통과
- `IOU 0.5`에서는 중복 검출로 일부 검출 개수 기준 실패

**확인이 필요한 내용**

- `IOS` 사용 승인 여부
- 최종 match threshold
- 최종 운영 후처리 방식
- 변경 승인 시 모델카드와 골든 생성 설정의 수정 여부
